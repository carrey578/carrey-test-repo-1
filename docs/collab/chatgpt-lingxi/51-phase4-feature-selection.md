## 二、推荐最优先项

**推荐：候选 1 - 统一入口 (dev-entry.sh)**

### 推荐理由

| 理由 | 说明 |
|------|------|
| **完成度高** | 已具备：脚本 + 验证 + 使用文档 + 开发文档 + 参数支持 + 模块化 |
| **核心入口** | 是所有其他功能的统一入口，补齐后能带动整体 |
| **可闭环强** | 补 verify → test checklist → regression → rollback → handoff 后可形成完整闭环 |
| **风险低** | 纯脚本改动，不影响核心运行 |
| **收益大** | 完善后可作为其他功能的参考模板 |

### 补齐后预期结构

```
dev-entry.sh 完整闭环：
├── 功能实现 (scripts/dev-entry.sh)
├── 验证入口 (scripts/verify-dev-entry.sh)
├── 测试清单 (docs/feature-test-checklist.md)
├── 回归检查 (regression-checklist.md)
├── 回滚说明 (rollback-guide.md)
├── 使用说明 (docs/feature-usage-guide.md)
├── 开发说明 (docs/feature-dev-notes.md)
└── Handoff (docs/collab/chatgpt-lingxi/43-feature-handoff.md)
```
