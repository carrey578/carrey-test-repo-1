## 二、职责分工

### 2.1 人工 (孟安然)

| 职责 | 说明 |
|------|------|
| **任务拆解** | 将需求拆分为可执行的任务项 |
| **开发执行** | 本地代码开发、Cursor 编辑 |
| **Review** | 人工审查代码/文档变更 |
| **验收** | 确认任务完成是否符合预期 |
| **决策** | 重大事项决策、方向把控 |
| **Handoff 确认** | 确认交接内容 |

### 2.2 灵犀

| 职责 | 说明 |
|------|------|
| **任务执行** | 执行分配的任务 |
| **文档编写** | 生成/更新文档 |
| **脚本编写** | 编写自动化脚本 |
| **自检验证** | 执行 verify 脚本自我检查 |
| **状态报告** | 生成状态报告 |
| **Handoff 生成** | 自动生成交接文档 |

### 2.3 ChatGPT

| 职责 | 说明 |
|------|------|
| **方案设计** | 提供方案思路和设计建议 |
| **文档整理** | 帮助整理和优化文档 |
| **问题分析** | 分析问题、提供解决方案建议 |
| **知识辅助** | 提供技术知识支持 |

### 2.4 Codex CLI

| 职责 | 说明 |
|------|------|
| **代码分析** | 分析代码结构、依赖关系 |
| **只读任务** | 代码搜索、阅读、理解 |
| **轻量文档** | 生成简单的文档摘要 |

## 三、接力流程

### 3.1 任务接力顺序

```
┌─────────────┐
│   人工      │  1. 拆解任务 → 明确目标
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  灵犀/ChatGPT │  2. 灵犀执行任务 / ChatGPT 提供方案
└──────┬──────┘
       │
       ▼
┌─────────────┐
│   灵犀     │  3. 自检 verify → 生成报告
└──────┬──────┘
       │
       ▼
┌─────────────┐
│   人工      │  4. Review + 验收
└─────────────┘
```

### 3.2 各阶段负责人

| 阶段 | 主要负责人 | 辅助 |
|------|------------|------|
| 任务拆分 | 人工 | ChatGPT |
| 执行 | 灵犀 | - |
| 自检 | 灵犀 | Codex |
| Review | 人工 | ChatGPT |
| 验收 | 人工 | - |
| Handoff | 灵犀 | 人工确认 |

## 四、推荐流程

### 4.1 日常任务流程

```markdown
1. 人工提供任务说明（消息/文档）
2. 灵犀确认理解任务目标
3. 灵犀执行任务
4. 灵犀自测 verify
5. 灵犀生成 handoff
6. 灵犀 commit + push
7. 人工 Review + 确认
```

### 4.2 方案设计流程

```markdown
1. 人工提出需求
2. ChatGPT 提供方案建议
3. 人工确认方案
4. 灵犀执行
5. 按日常流程继续
```

### 4.3 代码分析流程

```markdown
1. 人工/灵犀提出分析需求
2. Codex 执行只读分析
3. 返回分析结果
4. 灵犀/人工决策
```

## 五、容易冲突的场景与规避

### 5.1 场景1：多 Agent 同时处理同一任务

| 问题 | 灵犀和 ChatGPT 同时生成文档 |
|------|------------------------------|
| 规避 | 明确分工：灵犀负责执行，ChatGPT 负责建议 |

### 5.2 场景2：人工与 AI 产出冲突

| 问题 | AI 产出与人工预期不符 |
|------|----------------------|
| 规避 | 人工 Review 环节严格把关，不符合则打回 |

### 5.3 场景3：权限边界模糊

| 问题 | 灵犀执行了未授权的操作 |
|------|------------------------|
| 规避 | 遵守 SKILL.md 中的权限规则，不越权 |

### 5.4 场景4：Handoff 信息不完整

| 问题 | 自动生成的 handoff 缺少关键信息 |
|------|--------------------------------|
| 规避 | 人工补充区务必填写，Review 时检查 |
