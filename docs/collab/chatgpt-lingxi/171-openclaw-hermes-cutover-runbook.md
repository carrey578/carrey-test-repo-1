## 3. 最小可用 / 正式接管 / 切换完成 的区别

### 3.1 状态 A：迁移准备完成

- [ ] 已完成切换前备份
- [ ] 已完成快照 / 自定义镜像
- [ ] 已安装 Hermes
- [ ] `hermes claw migrate --dry-run` 结果合理

结论口径：

- [ ] 如果正式 `migrate` 未执行，只能记为“迁移准备完成”

### 3.2 状态 B：Hermes 最小可用

- [ ] `hermes --version` 正常
- [ ] `hermes doctor` 无致命错误
- [ ] Hermes CLI 可进入
- [ ] `/help` 或基础命令正常
- [ ] 至少完成一轮真实模型对话
- [ ] 已明确记录正式 `migrate` 是否执行

结论口径：

- [ ] `Hermes 最小可用` 不等于 `Hermes 正式接管`

### 3.3 状态 C：Hermes 正式接管

- [ ] Hermes 已成为实际主入口
- [ ] OpenClaw 已退出主运行位
- [ ] 平台侧 / 飞书 / 网关验证通过
- [ ] 日志中已明确记录当前活跃服务是 Hermes

### 3.4 状态 D：切换完成

- [ ] 已达到 `Hermes 最小可用`
- [ ] 已达到 `Hermes 正式接管`
- [ ] 本地 4.6 收尾验收通过
- [ ] 172 日志已写回并记录实际偏差
- [ ] 回滚入口和当前风险已复核
