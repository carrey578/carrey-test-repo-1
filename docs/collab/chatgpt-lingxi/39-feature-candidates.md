## 三、最推荐先做：功能点 3

**推荐理由**：
1. **收益高**：增强统一入口，让一个命令调用全套工具
2. **风险低**：仅修改 dev-entry.sh，不影响其他脚本
3. **联动强**：让现有脚本真正形成工具链
4. **可迭代**：后续可继续扩展调用能力

**预期效果**：
```bash
# 增强后的统一入口
bash scripts/dev-entry.sh all    # 运行所有检查
bash scripts/dev-entry.sh report  # 生成完整报告
```
