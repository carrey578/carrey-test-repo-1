# 138-model-routing-matrix-v2

> 模型路由矩阵 v2。指导不同任务类型如何选择执行模型。

---

## 路由规则总览

| 任务类型 | 默认执行方 | 是否允许外部模型 | 升级条件 | 备注 |
|----------|------------|------------------|----------|------|
| 方案设计 / 拆解 | ChatGPT | ❌ 否 | - | 默认本地控制层 |
| 仓库巡检 / 文档 / README | Coding Plan | ❌ 否 | - | 默认低成本 |
| 低风险 docs/scripts/tools 修改 | Coding Plan | ❌ 否 | - | 先默认模型 |
| 跨文件复杂重构 / 深读仓 | 外部模型（需授权） | ✅ 是 | 人工授权 | 只做短任务 |
| 最终验收 / 看 diff / 放权判断 | 人工 | ❌ 否 | - | 本地完成 |

---

## 详细说明

### 方案设计 / 拆解
- **默认**：ChatGPT（你本地）
- **外部模型**：不允许
- **原因**：规划类任务不需要模型能力，需要你的业务判断
- **边界**：不要让外部模型参与规划

### 仓库巡检 / 文档 / README
- **默认**：Coding Plan（Tencent Cloud MiniMax M2.5）
- **外部模型**：不允许
- **原因**：巡检和文档是低成本任务，默认模型足够
- **边界**：不要浪费外部模型配额在这类任务上

### 低风险 docs/scripts/tools 修改
- **默认**：Coding Plan
- **外部模型**：不允许
- **原因**：简单修改默认模型足够胜任
- **边界**：即使多次失败，也不优先升级，而是先简化任务

### 跨文件复杂重构 / 深读仓
- **默认**：Coding Plan（先尝试）
- **外部模型**：✅ 需授权
- **升级条件**：
  - 需要分析整个代码库
  - 跨文件复杂重构
  - 长上下文理解
  - 需要第二意见
- **边界**：
  - 必须先申请授权
  - 任务完成后必须回退
  - 记录到 133

### 最终验收 / 看 diff / 放权判断
- **默认**：人工（你）
- **外部模型**：不允许
- **原因**：验收需要你的业务判断，模型无法替代
- **边界**：这是人工专属区

---

## 授权申请模板

当灵犀需要升级到外部模型时，应发送以下格式的授权申请：

```
申请使用外部模型：[模型名]
原因：[为什么默认模型不够]
任务：[具体要做什么]
预计轮数：[1-2轮]
预计成本级别：[低/中/高]
预计结束条件：[什么时候算完成]
```

## 回退要求

- 外部模型任务完成后**必须**立即回退
- 回退脚本：`/root/workspace/config/model-routing/restore-default-route.sh`
- 验证：确认 `APPROVED=0` 且路由回到 Coding Plan
