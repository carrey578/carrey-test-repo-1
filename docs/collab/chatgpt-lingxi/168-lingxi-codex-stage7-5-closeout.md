## 五、当前可用边界

### 当前推荐使用边界
- 本地 Windows（Surface）环境
- 已登录的 Codex CLI
- 仓库本地目录
- 试点分支：`work/lingxi-codex-bootstrap`
- 单文件、低风险、边界清晰的任务
- 文档类修改或脚本中的用户可见文案级修改

### 当前不建议扩展的范围
- 多文件联动复杂修改
- 脚本逻辑级改造
- 主分支直接操作
- 云端灵犀侧把 Codex 作为主执行链
- API 计费模式下的扩张性试验
