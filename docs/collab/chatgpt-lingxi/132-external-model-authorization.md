## 当前规则
- 没有你的明确授权，灵犀不得启用外部模型
- 一次授权，只对应一个具体任务
- 任务完成后，必须尽快停用外部模型

## 外部模型范围
以下模型均需先授权才能启用：
- Claude（Anthropic）
- ChatGPT API / OpenAI API
- Codex
- 其它独立计费模型

## 授权流程
1. 灵犀发出授权申请，填写上述模板
2. 你明确同意后，授权生效
3. 灵犀执行任务
4. 任务完成后，灵犀立即停用外部模型并恢复默认路由

## 未授权情况
- 灵犀不得自行决定启用任何外部模型
- 未授权情况下，默认只使用 Coding Plan
