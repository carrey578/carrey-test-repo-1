# Handoff Template V1

## 模板说明

本模板用于多 AI / 人工协作时的任务交接。

## 适用场景

- 灵犀 → 人工交接
- 人工 → 灵犀派任务
- 不同 AI 工具间协作

---

## 必填项

| 字段 | 说明 | 示例 |
|------|------|------|
| `handoff_from` | 交接方 | 灵犀 |
| `handoff_to` | 接收方 | 人工 |
| `timestamp` | 交接时间 | 2026-03-24 23:30 |
| `task_name` | 任务名称 | 生成仓库结构图 |

## 结构化内容

### 1. 本轮完成

- 完成了什么
- 产出文件
- commit id

### 2. 下一轮建议

- 建议下一步做什么
- 优先级
- 理由

### 3. 风险/阻塞

- 有无风险
- 有无阻塞项

### 4. 待确认

- 需要人工确认的事项
- 需要决策的事项

---

## 使用方式

1. 任务完成需要交接时，复制本模板
2. 填写必填项
3. 补充结构化内容
4. 放入 docs/collab/chatgpt-lingxi/
5. 提交并 push
