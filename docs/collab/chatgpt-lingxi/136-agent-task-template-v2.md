# 136-agent-task-template-v2

> Agent Harness 任务模板 v2。每次执行任务前必须填写。

---

## 必填字段

### 任务名称
> 简要描述任务名称

```
例如：修复 README 格式问题
```

### 目标
> 任务要达成什么结果

```
例如：使 README 在移动端可正常显示
```

### 修改范围
> 具体要改哪些文件/目录

```
例如：
- docs/README.md
- docs/style.css
```

### 输入
> 任务依赖什么信息/文档/上下文

```
例如：
- 方案 4.4 文档
- 当前仓库结构
```

### 输出
> 任务完成后产出什么

```
例如：
- 修复后的 README.md
- commit + push
```

### 验收标准
> 怎么算完成任务

```
例如：
- README.md 在手机浏览器可正常显示
- diff 已 push 到 origin
```

---

## 外部模型相关（关键）

### 是否允许外部模型
```
选项：是 / 否
默认值：否
```

### 如允许，是否已获授权
```
选项：是 / 否
前置条件：必须先拿到人工授权才能选"是"
授权文件：132-external-model-authorization.md
```

### 完成后是否需要回退默认路由
```
选项：是 / 否
默认值：是
说明：除非特殊原因，否则外部模型任务完成后必须回退
```

---

## 禁止事项

- ❌ 未经授权，不得使用外部模型
- ❌ 不得在任务完成后继续使用外部模型
- ❌ 不得修改 main 分支
- ❌ 不得修改系统配置（除非方案明确要求）

---

## 填写示例

```
## 任务：优化代码注释

### 目标
为核心函数添加中文注释，提升可读性

### 修改范围
- src/utils/helper.js
- src/core/parser.js

### 输入
- 当前代码结构
- 中文注释规范

### 输出
- 添加注释后的 JS 文件
- commit: "docs: add Chinese comments to core functions"

### 验收标准
- 所有导出函数都有中文 JSDoc
- 代码可正常运行

### 是否允许外部模型：否

### 如允许，是否已获授权：否

### 完成后是否需要回退默认路由：是
```
