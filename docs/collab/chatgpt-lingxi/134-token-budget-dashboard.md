## 维护规则

### 更新频率
- 每次使用外部模型后更新
- 至少每月review一次

### 状态定义

| 状态 | 含义 | 建议动作 |
|------|------|----------|
| 正常 | 月预算未超 80% | 继续正常授权 |
| 偏紧 | 月预算 80%~100% | 谨慎授权，优先低成本方案 |
| 冻结 | 月预算已超 | 暂停外部模型授权 |

### 成本级别定义

| 级别 | 定义 |
|------|------|
| 低 | 单次任务 < 50k tokens，预计成本 < $0.5 |
| 中 | 单次任务 50k~200k tokens，预计成本 $0.5~$2 |
| 高 | 单次任务 > 200k tokens，预计成本 > $2 |
